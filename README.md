# RATP
Transport App Project using RATP Api and data 
 
OBJECTIVE

RATP is a public transport application which allows the user to navigate throw Ile-de-France.
Our goal is to have a user-oriented web-based application coded in C++. 
The app is meant to be "ready ot use" the user shouln't go throw a long and complex process in order to access his journey. 
The paradigm that we chosed is eclological, responsible and durable. We will incorporate the Velib stations, nice walk that could replace parts of the journey. 

FUNCTIONS 

The different functions that we will implement will be the following : 

-	Itinerary calculation and display starting by the shortest and then with options like : with bycicle, with a walk… 
-	Display of the subway maps
